# MEY Taxi München

Static website prepared for GitHub Pages.

## Upload to GitHub
1. Create or open a GitHub repository.
2. Upload the contents of this folder to the repository root (not the ZIP itself).
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and the root `/` folder, then save.

`index.html` is already in the repository root and the site uses relative asset paths.
